Isolation Forest: Phát hiện bất thường bằng cô lập ngẫu nhiên

Tác giả gốc: Fei Tony Liu, Kai Ming Ting, Zhi-Hua Zhou (ICDM 2008). Tài liệu tổng hợp cho mục đích minh hoạ định dạng.

Tóm tắt: Isolation Forest (iForest) là thuật toán học không giám sát để phát hiện điểm bất thường (anomaly). Ý tưởng cốt lõi: điểm bất thường “ít và khác” nên dễ bị cô lập hơn điểm bình thường.

1. Trực giác

Thay vì mô hình hoá phân phối của dữ liệu bình thường rồi tìm điểm lệch (như nhiều phương pháp khác), iForest chủ động cô lập từng điểm bằng cách cắt không gian một cách ngẫu nhiên. Điểm bất thường nằm thưa thớt → bị tách ra chỉ sau vài lần cắt → độ sâu nhỏ trong cây.

“Anomalies are few and different, which make them more susceptible to isolation.” — Liu et al., 2008

2. Công thức điểm bất thường

Với tập n mẫu, độ dài đường đi trung bình của một cây nhị phân tìm kiếm không thành công là:

c(n) = 2·H(n − 1) − ( 2·(n − 1) / n )

trong đó H(i) ≈ ln(i) + 0.5772156649 (hằng số Euler–Mascheroni). Điểm bất thường của mẫu x:

s(x, n) = 2−E(h(x)) / c(n)
  • s → 1: gần như chắc chắn là bất thường.
  • s ≈ 0.5: không phân biệt được rõ.
  • s < 0.5: nhiều khả năng là điểm bình thường.

3. Mã giả (Pseudocode)

# Xây một iTree
def iTree(X, e, l):
    if e >= l or len(X) <= 1:
        return exNode(size=len(X))
    q = random_feature(X)            # chọn thuộc tính ngẫu nhiên
    p = random_split(min_q, max_q)   # chọn ngưỡng cắt ngẫu nhiên
    Xl = X[X[q] < p]
    Xr = X[X[q] >= p]
    return inNode(left=iTree(Xl, e+1, l),
                  right=iTree(Xr, e+1, l),
                  split_att=q, split_val=p)

6. Ví dụ code Python

from sklearn.ensemble import IsolationForest
import numpy as np

X = np.random.randn(1000, 2)
clf = IsolationForest(n_estimators=100,
                      contamination=0.05,
                      random_state=42)
clf.fit(X)
scores = clf.decision_function(X)   # càng nhỏ càng bất thường
labels = clf.predict(X)              # -1 = anomaly, 1 = normal
Lưu ý thực tế: iForest nhạy với contamination. Đặt sai tỉ lệ này sẽ khiến mô hình gắn nhãn bất thường sai hàng loạt. Luôn kiểm định trên tập có nhãn nếu có.
